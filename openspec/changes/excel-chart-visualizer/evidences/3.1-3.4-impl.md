# 执行证据：3.1+3.4 实现 ParticleBackground + NeonTitle 组件

**完成时间**: 2026-05-28T00:00:00Z
**Category**: unspecified-high

## 实现摘要

成功创建了两个 Vue 3 组件：ParticleBackground.vue 实现了全屏 Canvas 粒子动画背景，使用原生 Canvas API 绘制 60 个蓝紫色系粒子，支持匀速漂浮和边界反弹；NeonTitle.vue 实现了带霓虹发光效果的标题组件，支持 title 和可选 subtitle props。两个组件均使用 `<script setup lang="ts">` 语法，构建验证通过。

## 变更文件清单

| 文件路径 | 操作 | 说明 |
|----------|------|------|
| src/components/ParticleBackground.vue | 新建 | 全屏 Canvas 粒子动画背景组件 |
| src/components/NeonTitle.vue | 新建 | 霓虹发光效果标题组件 |

## 关键实现细节

1. **ParticleBackground.vue**:
   - 使用 `ref` 引用 canvas 元素
   - 在 `onMounted` 中初始化 Canvas 上下文和粒子数组
   - 粒子参数：60 个粒子，大小 1-4px，透明度 0.1-0.5，速度 -0.3 到 0.3
   - 颜色从 `#3b82f6`、`#a855f7`、`#6366f1` 中随机选择
   - 使用 `requestAnimationFrame` 实现动画循环
   - 支持 `resize` 事件更新 canvas 尺寸
   - 在 `onUnmounted` 中清理动画帧和事件监听

2. **NeonTitle.vue**:
   - 使用 `defineProps` 定义 `title` (必填) 和 `subtitle` (可选) props
   - 霓虹效果通过 CSS `text-shadow` 实现，使用 global.css 中定义的颜色变量
   - subtitle 样式使用 `var(--text-secondary)` 颜色
