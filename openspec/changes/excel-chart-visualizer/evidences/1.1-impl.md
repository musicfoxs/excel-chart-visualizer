**完成时间**: 2026-05-28T16:01:00+08:00
**Category**: unspecified-high

## 实现摘要

在当前目录初始化了 Vue 3 + TypeScript + Vite 项目。由于目录非空（存在 .git 和 openspec 文件夹），使用临时子目录创建项目后移动文件到根目录。安装了 echarts 和 xlsx 生产依赖。创建了 ECharts 按需引入入口文件，配置了 BarChart、TooltipComponent、GridComponent、LegendComponent 和 CanvasRenderer。配置了 TypeScript 和 Vite 的 `@` 路径别名指向 `src/` 目录。由于 Node.js 版本限制（当前 20.12.2），将 Vite 从 8.x 降级到 6.x 以确保兼容性。

## 关键实现细节

1. **Vite 版本降级**：原 Vite 8.x 要求 Node.js 20.19+ 或 22.12+，当前环境为 20.12.2。降级到 Vite 6.x（配合 @vitejs/plugin-vue 5.x 和 TypeScript 5.8.x）以兼容当前 Node.js 版本。

2. **ECharts 按需引入**：`src/echarts.ts` 使用 tree-shaking 友好的按需引入方式，仅注册必要的图表类型（BarChart）和组件，后续所有组件统一从此文件 `import echarts from '@/echarts'` 使用，减少打包体积。

3. **路径别名配置**：需要在两处配置：
   - `tsconfig.app.json`: 添加 `baseUrl` 和 `paths` 配置
   - `vite.config.ts`: 添加 `resolve.alias` 配置
