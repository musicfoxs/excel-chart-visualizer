## 实现摘要

创建了 `src/composables/useChartOptions.ts`，实现了 ECharts 配置生成器 composable。使用 `@/echarts` 按需引入版本创建 LinearGradient 渐变色，传统组为蓝紫渐变，创新组为橙粉渐变。配置包含毛玻璃风格 tooltip、发光阴影效果（默认 shadowBlur: 15，悬浮增强至 25）、弹性入场动画（elasticOut，按索引递增延迟 200ms）。所有颜色参数严格遵循设计规格。

## 关键实现细节

1. **渐变色方向**：LinearGradient(0, 0, 0, 1) 表示从顶到底，offset 0 为顶部色，offset 1 为底部色
2. **阴影颜色**：传统组使用紫色 rgba(168, 85, 247, 0.6)，创新组使用粉色 rgba(244, 114, 182, 0.6)
3. **动画延迟**：每个分类递增 200ms，使柱子依次出现
4. **圆角**：borderRadius [6, 6, 0, 0] 对应 [左上, 右上, 右下, 左下]
5. **必须从 `@/echarts` 导入**：不能直接从 `echarts` 导入，否则会引入完整包
