# 执行证据：3.2+3.3 实现 FileUpload + ChartCard 组件

**完成时间**: 2026-05-28T10:15:00+08:00
**Category**: unspecified-high

## 实现摘要

成功实现了两个核心 Vue 3 组件。FileUpload.vue 提供拖拽和点击两种上传方式，支持 loading/error 状态显示，使用毛玻璃卡片样式和霓虹蓝发光高亮效果。ChartCard.vue 作为 ECharts 图表容器，使用 ResizeObserver 实现响应式调整，自动监听 block prop 变化更新图表，并在组件卸载时正确销毁实例防止内存泄漏。

## 关键实现细节

1. **FileUpload.vue**:
   - 使用 `ref<HTMLInputElement>` 管理隐藏的 file input
   - 拖拽状态通过 `isDragOver` ref 控制，拖拽时边框变为霓虹蓝发光效果
   - loading 状态使用 CSS 动画的 spinner
   - 重置 input.value 允许重复上传同一文件
   - 使用 `glass-card` 类继承全局毛玻璃样式

2. **ChartCard.vue**:
   - 使用 `echarts.init()` 初始化实例，指定 canvas 渲染器
   - 通过 `ResizeObserver` 监听容器尺寸变化调用 `chart.resize()`
   - `watch(() => props.block, updateChart, { deep: true })` 深度监听数据变化
   - `onUnmounted` 中正确销毁 ResizeObserver 和 ECharts 实例
   - 使用 `@/echarts` 按需引入版本而非完整包

3. **样式约定**:
   - `class="file-upload"` 和 `class="chart-card"` 用于 DOM 断言
   - 继承全局 `glass-card` 类和 `fade-in-up` 动画
   - 响应式宽度：FileUpload max-width 500px，ChartCard 图表容器 height 300px
