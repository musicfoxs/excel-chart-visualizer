## 新增的三层类型

### Layer 1: ParsedDocument / ParsedModule / ParsedIndicator
- 每个 Word 文档的解析结果
- 保留文件名、分组（innovative/traditional）、模块列表、指标及勾选等级

### Layer 2: AggregatedModule / AggregatedIndicator
- 跨文档聚合结果（per module）
- 指标包含 levelLabels 与 innovativeCounts / traditionalCounts 一一对应

### Layer 3: ChartBlock / ChartIndicator
- ECharts-ready 图表数据
- indicators 数组中每项包含 labels / innovative / traditional

### UI 状态类型
- `GroupType`, `TabId`, `TabConfig`, `TABS`, `MODULE_MAPPING`
