## Implementation Summary

### Core Architecture
- **JSZip** decompresses `.docx` → extracts `word/document.xml`
- **DOMParser** parses XML into DOM tree
- **State machine** walks table rows 3-12, tracking module boundaries via `w:vMerge`

### Key Helpers
| Helper | Purpose |
|--------|---------|
| `getElements(parent, localName)` | Namespace-aware element query with fallback |
| `getFirstElement(parent, localName)` | First match helper |
| `getAttr(el, localName)` | Namespace-aware attribute getter |
| `extractCellText(tc)` | Aggregates fragmented `w:r`/`w:t` text, handles `w:br` soft returns |
| `getVMerge(tc)` | Detects `w:vMerge` restart/continue/none |
| `getGridSpan(tc)` | Reads `w:gridSpan` for horizontal merge |
| `extractCheckedLevels(text)` | Regex extracts ☑/✓/√ checked labels and □ unchecked labels |

### Parsing Logic
1. Rows 1-2 (headers) skipped
2. Rows 3-6: "爱上阅读（阅读兴趣）" module (4 indicators)
3. Rows 7-10: "学会阅读（阅读水平）" module (4 indicators)
4. Rows 11-12: "个体差异关注" module (2 indicators)
5. Column mapping: col 1=module name (vMerge), col 2=indicator name, col 3=content, col 5=rating levels
