# Task 4.1 执行证据：重构 App.vue 整合所有新组件

## 变更摘要

完全重写 `src/App.vue`，从单文件上传 + Excel 解析的旧架构，迁移到双入口上传 + TabBar 导航 + 模块化图表 + 总体对比的新架构。

## 具体变更

### 文件：`src/App.vue`（完全重写）

**移除的导入：**
- `FileUpload` 组件（不再使用）
- `useExcelParser` composable（不再使用）

**新增的导入：**
- `GroupUpload` — 双入口上传组件（创新组 + 传统组）
- `TabBar` — 4 个 Tab 导航（爱上阅读/学会阅读/个体差异/总体对比）
- `ChartCard` — 图表卡片（接收 `indicator` prop）
- `useDocxParser` — Word .docx 文件解析
- `useStatAggregation` — 多文档聚合 + ChartBlock 生成
- 类型导入：`ParsedDocument`, `GroupType`, `TabId`, `ChartBlock`
- 常量导入：`MODULE_MAPPING`（模块名 → TabId 映射）

**新增 State：**
- `innovativeFiles: ref<File[]>` — 创新组文件列表
- `traditionalFiles: ref<File[]>` — 传统组文件列表
- `parsedDocuments: ref<ParsedDocument[]>` — 所有解析文档
- `activeTab: ref<TabId>` — 当前激活 Tab
- `loading: ref<boolean>` — 全局加载状态
- `errors: ref<{innovative, traditional}>` — 分组错误信息

**新增 Computed：**
- `aggregatedModules` — 调用 `aggregate()` 聚合所有文档
- `chartBlocks` — 调用 `toChartBlocks()` 生成每模块 ChartBlock
- `overallChartBlock` — 调用 `toOverallChartBlock()` 生成总体对比
- `hasData` — 是否有已解析数据
- `currentChartBlock` — 根据当前 Tab 返回对应的 ChartBlock（通过 MODULE_MAPPING 映射或 overall 特殊处理）

**新增 Handlers：**
- `handleFilesSelected(group, files)` — 异步解析上传文件，追加到 parsedDocuments，支持错误捕获
- `handleTabChange(tabId)` — 切换当前 Tab

**Template 结构：**
```
ParticleBackground
└── app-content
    ├── header: NeonTitle（"绘本阅读量表分析"）
    └── main
        ├── GroupUpload（双入口上传）
        ├── data-section（v-if hasData）
        │   ├── TabBar
        │   └── chart-grid（v-for indicator in currentChartBlock.indicators）
        └── empty-state（v-else）
```

**样式：**
- 保留原有的 `.app-content`, `.app-header`, `.app-main` 样式
- 新增 `.data-section`, `.chart-grid`, `.empty-state` 样式
- 保留响应式断点 `@media (max-width: 768px)`

## 关键设计决策

1. **ChartCard 传递 `indicator` prop**：每个 `ChartIndicator` 单独传递给 ChartCard（而非整个 block），ChartCard 将在 4.2 中重构以支持此新接口
2. **文件追加而非替换**：`handleFilesSelected` 追加新文件到已有列表，支持多次上传
3. **Tab 路由通过 MODULE_MAPPING**：`chartBlocks` 的 title（模块名）通过 `MODULE_MAPPING` 映射到 TabId，实现模块与 Tab 的关联
4. **overall 特殊处理**：`activeTab === 'overall'` 时直接返回 `overallChartBlock`，不经过 MODULE_MAPPING
