## Template Structure
```html
<div class="tab-bar glass-card">
  <button 
    v-for="tab in TABS" 
    :key="tab.id"
    class="tab-item"
    :class="{ active: tab.id === activeTab, disabled: disabled }"
    :disabled="disabled"
    @click="$emit('tabChange', tab.id)"
  >
    {{ tab.label }}
  </button>
</div>
```
